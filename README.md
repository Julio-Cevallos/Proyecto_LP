# Proyecto_LP
## 🛠️ Requisitos e Instalación
Para poder probar y ejecutar los analizadores (léxico, sintáctico y semántico) de este proyecto, es necesario contar con **Python 3.x** y las dependencias correspondientes.

### Archivo de Dependencias
Las bibliotecas requeridas se encuentran especificadas en el archivo de la raíz:
* `requirements.txt`

### Instrucciones de Instalación
Para instalar de forma automática todas las bibliotecas necesarias, abre una terminal en la ruta raíz del proyecto y ejecuta el siguiente comando:

```bash
pip install -r requirements.txt
```
